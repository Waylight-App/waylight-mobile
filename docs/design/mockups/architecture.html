Widgets without cross-feature imports

The dashboard only knows a WidgetRegistry (ui/core). Each widget lives in its own feature folder; the composition root registers the renderers by widget kind. Unknown kinds get the fallback card.

Navigation follows state

Connect, sign-in, sign-out and session expiry change a repository; GoRouter listens and redirects. Screens never decide where to go after an action.
